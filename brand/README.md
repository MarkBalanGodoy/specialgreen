# Special Green LLC — Logo

Open `logo-sheet.html` in a browser. It shows every version, how the mark holds up small, the
colours, and the rules.

## The idea

A sprig rising from a ground rule. Two leaves rather than one, so it reads as planting rather
than a generic leaf, and chunky enough to survive 16 pixels and embroidery thread. The orange
ground rule is the only orange in the mark, and it is what ties the logo to the crew shirts.

The service line under the wordmark is what says what the company does. It reads
**Lawns · Landscaping · Irrigation**, and deliberately no longer says Pools, because the site
does not sell pool service. If pool service comes back, the service line goes back with it.

## Rules

- Clear space on every side is the height of the ground rule. Nothing crowds it.
- Minimum width for the horizontal lockup is 160px on screen, 1.25 inches in print. Below
  that, use the stacked version or the mark alone.
- Do not recolour the leaves, restack the words, add a shadow, outline it, or set it on a busy
  photo. On a photo, use the one-colour white version over a darkened area.
- The service line is part of the logo. If it is too small to read, use the mark alone rather
  than shrinking the words.

## One thing before this goes to a printer

The mark is pure vector paths and is final art. It will render identically anywhere.

The wordmark is **live text set in Oswald**, not outlined. On the website that is correct and
preferable, because the browser loads the font. For anything going to a print shop, a vinyl
cutter, or an embroiderer, the type has to be converted to outlines first, or their machine
will substitute a different font and the logo will come back wrong.

Outlining is a two-minute job in Illustrator, Figma, or Inkscape (select the text, then Type >
Create Outlines, or Path > Object to Path). Do it once, save the outlined files alongside
these, and hand those to vendors.

Type spec, if anyone needs to reset it: Oswald Bold, uppercase, letter-spacing 1.6 for the
wordmark. Service line in Inter Bold, uppercase, letter-spacing 4.6, at roughly 28% of the
wordmark's size.
