# Special Green LLC — Logo

Open `logo-sheet.html` in a browser for every version, the colours and the rules.

## What changed

This is Special Green's own logo, rebuilt as clean vector from the artwork Mark had. Two words
were misspelled in the original:

| Was | Now |
| --- | --- |
| RESIDEN**C**IAL | RESIDEN**T**IAL |
| CO**M**ERCIAL | CO**MM**ERCIAL |

Both were the Spanish spellings paired with an English ampersand, which reads as a mistake
rather than a bilingual choice. Nothing else about the design was changed. The house-and-leaf
mark, the banner, the colours and the layout are all as they were.

The original was a raster image with no vector source, so it could not scale, could not be
knocked out to white, and could not be corrected. These files can.

## Rules

- The badge carries the phone number. The web lockup deliberately does not, so a change of
  number only means reissuing the badge rather than every asset the company owns.
- Do not recolour the leaves, restack the words, add a shadow, or set the badge on a busy
  photo. Over a photo, use the knockout on a darkened area.
- Minimum width for the badge is 1.25 inches in print. Below that, use the mark alone.

## Two things still to decide

**The badge says LAWN CARE & LANDSCAPING and leaves out irrigation.** The company sells
irrigation and the website says so, so the badge and the site currently disagree. The web
lockup reads LAWN CARE · LANDSCAPING · IRRIGATION. Worth reconciling before new signs or
shirts are ordered.

**The wordmark is live text, not outlined.** "Special Green" is set in Bitter Bold and the rest
in Oswald. That is correct on the web, because the browser loads the fonts. Anything going to a
print shop, a vinyl cutter or an embroiderer needs the type converted to outlines first, or
their machine will substitute a different font. Two minutes in Illustrator, Figma or Inkscape:
select the text, then Type > Create Outlines, or Path > Object to Path. Save those alongside
these and hand the outlined files to vendors.

The original artwork used different fonts, which were not supplied with it. These are close
matches, not the exact originals. If Mark can find whoever built the first version and get the
source file, the type can be matched exactly.
